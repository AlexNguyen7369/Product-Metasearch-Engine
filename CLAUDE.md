# Project Instructions

## Progress tracking (required after every commit or push)
After making a commit or push in this repo, read and follow
`prompt_templates/progress_tracker_prompt.md` in full before touching
`current_progress.md` — it is the authoritative, strict spec for how that
file is created (if missing) and updated (Completed appends, What's Next
replacement, formatting, attribution). Do not improvise the update from
memory or from this summary; call up that file every time this rule fires.

Do this as part of the same commit whenever practical, so the progress file
never drifts out of sync with actual repo state.
