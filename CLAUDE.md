# Project Instructions

## Progress tracking (required after every commit or push)
After making a commit or push in this repo, update `current_progress.md`:
- **Completed**: append the task just finished to the end of the list, in
  sequential order, with the date and the committing user. One line each —
  do not let this section get lengthy; keep entries short.
- **What's next**: replace it with the next logical task, plus a short
  reasoning tied to what depends on it (e.g. "future feature X builds on
  this").

Do this as part of the same commit whenever practical, so the progress file
never drifts out of sync with actual repo state.
